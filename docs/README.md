details live next to the code instead (`backend/README.md`, `backend/ai/README.md`,
`backend/policy/README.md`, `browser-extension/README.md`, `knowledge/README.md`,
`tests/README.md`).

| Doc | Purpose |
|---|---|

| [`demo_script.md`](demo_script.md) | Step-by-step live demo script with sample prompts and expected outcomes |
| [`presentation.md`](presentation.md) | Slide-by-slide pitch outline (problem, solution, architecture, demo, roadmap) |
